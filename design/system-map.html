How Whetstone and Lodestone work

One engine, two jobs. Whetstone takes a player's prompt and builds the strongest version of that build, stage by stage. Lodestone uses the same engine to look for builds nobody has found. One rented server runs both, with a Claude session working through a task list around the clock.

Inside one stage, in order

  1. Conditions the build keeps up
  2. First gear
  3. Passive tree + ascendancy
  4. Support gems
  5. Spirit buffs, triggers
  6. Defensive buffs
  7. Curses, marks, banners
  8. Gear re-crafted to fit
  9. Ascendancy spent again
  10. Spirit check
  11. Jewels
  12. Boss setup, weapon set 2
  13. Supports for extra skills

Act stages are light: one tree pass, no jewels, no boss setups. Gear and uniques follow what a player realistically has at each stage, never a budget.
