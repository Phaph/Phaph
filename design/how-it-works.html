How it works

Five steps, all scored by Path of Building

Path of Building is the community's standard damage calculator: the numbers every guide quotes. Normally it's a desktop app you click through by hand. We run its engine with no window, so a program can ask it "what if?" thousands of times a minute.

STEP 1

Read the request

Class, ascendancy, main skill, weapon and budget. Each one is checked against the game data, so a typo or an impossible combo gets a clear error.

STEP 2

Craft gear

For every slot it picks the best base, then the best affixes from the game's real affix tables, capped at your budget. Resistances only go where they're still needed.

STEP 3

Spend passives

Every reachable passive and ascendancy node is tested. The one that adds the most damage and toughness per point is taken, then it repeats until the points run out.

STEP 4

Pick supports

Every support gem is tried on the skill, then the best 5-gem combination is built while respecting game rules: gem families, lineage limits, gems that need conditions.

STEP 5

Write the guide

Gear is re-tuned for the final tree. Then a mapping setup and a bossing swap, stats, pros and cons, and a PoB code you can import and check yourself.

Steps 2 to 5 run once per stage: Leveling (level 55), Early maps (75), Mid maps (90) and Endgame (95), in parallel. A full four-stage guide takes about a minute and a half. Asking for the same build again is instant, because results are cached.

Why it's different

It searches instead of guessing

Real math, not a chatbot's memory

AI build assistants mostly ask a language model what's good, which can mix up game versions or invent numbers. Here every recommendation is a number Path of Building calculated. AI only turns your words into a build request and writes up the result.

Niche builds get the same treatment

Guide sites cover what's popular. Here a weird idea like bleed Monk or minion Ranger gets the same full search as the meta builds, because nothing depends on someone having written a guide first.

Budget comes first

You pick a budget before anything else: free, 5, 30, 100 divines or no limit. Every stage stays inside it, so nobody is handed a 2,000 divine build. A 5 divine player still gets mapping and endgame versions built from gear they can afford.

Gear is a shopping list

Each slot gets a base type and affixes in the order to buy them, with target values and tiers matched to the budget. It's ready to paste into a trade search, rather than "get life and resistances".

Mapping and bossing, both

Same gear and passives, two support setups. Mapping favours area and clear, bossing favours single-target damage. The tool tells you which gems to swap.

Fair comparisons

Give it up to three builds. Each one is fully built at the same budget before comparing, so you see real damage, toughness and resistances side by side with plain pros and cons, not one optimised build against two rough ones.

Same answer every time

Identical requests give identical builds. We fixed a hidden source of randomness in the engine that made results drift between runs, so you can trust a number and share it.

Checked on every change

35 automated tests cover game rules (Bleed IV stops bleeding, lineage gem limits), past bugs and the website's API. A sweep builds every one of the 23 ascendancies to catch breakage before players do.

Honest status

What's built, and what isn't yet

  • Built and tested: the engine, support and passive optimisers, gear crafting, four stages, budgets, mapping vs bossing, comparisons, the web API with caching, a Docker package.
  • Not built yet: the website itself, and the plain-English request box (it needs an API key).
  • Missing from builds: unique items and real trade prices, which need data from poe.ninja. Budgets in divines are estimates until then.
  • Known limits: the passive search is greedy and can miss a strong node hidden behind weak ones. Path of Building has no clear-speed stat, so the mapping score is our own estimate.
  • Patch 1.0 (Dec 11): the new Shadow and Duelist classes work as soon as Path of Building adds them. Everything else updates with it automatically.
